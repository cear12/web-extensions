1. Автокопирование ссылок
Клик по кнопке расширения — текущий URL в буфере обмена.

Минимальное количество кода, востребовано с любым типом контента.

Монетизация: микроплатежи за bulk-экспорт и историю копирования.

Техническое задание для Cursor IDE: Трансформация QR-генератора в расширение автокопирования ссылок
🎯 ЗАДАЧА
Переработать существующее Chrome расширение для генерации QR-кодов в расширение для автоматического копирования ссылок с расширенным функционалом монетизации.

📋 ТЕХНИЧЕСКОЕ ЗАДАНИЕ
ОСНОВНАЯ ФУНКЦИОНАЛЬНОСТЬ
Core Feature:

text
Создать Chrome расширение "QuickLink Copier", которое позволяет:
1. Копировать текущий URL одним кликом по иконке расширения
2. Копировать любую ссылку через контекстное меню (правый клик)
3. Сохранять историю скопированных ссылок
4. Экспортировать ссылки в различных форматах

ДЕТАЛЬНЫЕ ТРЕБОВАНИЯ
1. MANIFEST.JSON
json
{
  "manifest_version": 3,
  "name": "QuickLink Copier",
  "version": "1.0.0",
  "description": "One-click link copying with history and export features",
  "permissions": [
    "activeTab",
    "contextMenus", 
    "storage",
    "clipboardWrite"
  ],
  "host_permissions": ["<all_urls>"],
  "action": {
    "default_popup": "popup.html",
    "default_title": "Copy current page URL"
  },
  "background": {
    "service_worker": "background.js"
  },
  "content_scripts": [{
    "matches": ["<all_urls>"],
    "js": ["content.js"]
  }],
  "options_page": "options.html"
}
